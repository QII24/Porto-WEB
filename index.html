Automatic Meeting Minutes System

AI / ML / NLP (Undergraduate Thesis)

Problem Statement

Manual transcription and minute-taking during meetings is time-consuming and prone to human error, creating a need for automated intelligence.

Objectives

To develop and evaluate an automated pipeline capable of converting spoken meeting audio into accurate text and summarizing the key points into minutes.

Methodology & Implementation

  • Implemented Automatic Speech Recognition (ASR) pipelines using state-of-the-art models.
  • Evaluated various speech enhancement techniques alongside language models to boost accuracy.
  • Employed Word Error Rate (WER) to rigorously compare transcription performance.

Tools & Technologies

  • Whisper
  • Wav2Vec2
  • Natural Language Processing methodologies
